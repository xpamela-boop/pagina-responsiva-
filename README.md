# 📰 Feed de Postagens Horizontais

Este projeto é um feed de postagens estilizado com **CSS Flexbox** para exibir cards na largura total da tela (`100%`) e com layout em linha (`row`).

---

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estruturação dos elementos.
* **CSS3**: Layout responsivo utilizando Flexbox (`flex-direction`, `align-self`, `flex`).
* **JavaScript (ES6+)**: Renderização dinâmica de postagens e interatividade.

---

## 🎨 Principais Ajustes no CSS (`style.css`)

* **`flex-direction: row;`**: Modificado no seletor `article` para alinhar a imagem, o conteúdo textual e os botões lado a lado.
* **`flex: 0 0 100%;`**: Garante que cada card ocupe 100% da largura da página/container.
* **`align-self`**: Utilizado em elementos internos (como a imagem ou o botão) para quebrar o alinhamento centralizado padrão e dar um destaque visual único.
